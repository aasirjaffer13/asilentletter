# Run Arvii's website locally

1. Install [Node.js](https://nodejs.org/) version 20 or newer.
2. Extract this ZIP and open the extracted folder in VS Code.
3. Open **Terminal → New Terminal**.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local address shown in the terminal (normally `http://localhost:3000`).

## Personalize the website

Edit `src/content/arvii.ts` to change names, messages, memories, date choices, and other personal text.

The opening song is selected from the visitor's device. It is not uploaded anywhere and never autoplays.
